# Changelog

## 0.3.0

This release requires Zig 0.17.0. It no longer supports Zig 0.16.0.

The schema emitter, validator, and JSON writer use the new reflection field arrays. Existing public schema APIs are unchanged. Build commands forward arguments through `addPassthruArgs`.

The package now includes its test inputs so the fetched package can run its tests. CI checks Debug and ReleaseSafe builds on Linux and macOS.

Keep the existing package fingerprint. Use an immutable release tag or commit and the package hash generated by Zig 0.17.0 when declaring this dependency.
